# Quantitative Finance in Python
This repository includes Python implementations of core quantitative-finance models (mean-variance optimisation, CAPM, futures and bond pricing) created as part of the exercises of the Udemy course "Quantitative Finance & Algorithmic Trading in Python" (see [here](https://www.udemy.com/course/quantitative-finance-algorithmic-trading-in-python/?couponCode=MT260902G1B)).

## Contents
- MarkowitzModel.py: mean-variance optimisation.
- CAPM.py: beta estimation, capital market line.
- Bonds.py: bond present value, duration, convexity, yield.
- PricingFuturesContract.py: determines fair futures price using a cost-of-carry model.
- PresentValue.py and ExerciseNormalDistribution.py: core building-blocks.
